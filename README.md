# orientplacment2026

Modern Next.js (App Router, TypeScript, Tailwind CSS) conversion of the Orion Placement legal recruiting website prototype.

## Features
- All 18 high-fidelity pages converted with exact typography, copy, and `#FAF9F5` paper theme.
- Google Fonts (`DM Serif Display`, `DM Mono`, `Inter`).
- Interactive tools: Fee Calculator, Candidate Search, Job Posting Parser, Salary Checker, Resume Intake.
- Responsive mobile & desktop mega-menus, gate forms, and reviews.

## Getting Started

```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
npm run start
```
